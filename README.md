# Velour — Premium Men’s Wellness Tracker

> A premium parody wellness tracker for men.  
> Built as a modern installable web app with subtle humor, smooth UI, and real behavioral tracking.

---

## ✨ Overview

Velour blends:
- Mood tracking
- Energy monitoring
- Stress insights
- Behavioral patterns
- “Male cycle” parody humor

into a polished, fast, and minimal Progressive Web App (PWA).

The app is intentionally playful while still delivering meaningful self-awareness and wellness insights.

---

# 🌐 Features

## 🏠 Dashboard
- Daily overview
- Mood & energy cards

- Quick insights
- Theme toggle
